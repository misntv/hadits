# 📚 KUMPULAN HADITS — MISNTV

**Data Kumpulan Hadits dalam Format JSON**

Repositori ini menyediakan kumpulan data hadis dalam format JSON yang dapat digunakan sebagai sumber data untuk aplikasi, pembelajaran, dan pengembangan layanan digital Islami.

Repositori GitHub: https://github.com/misntv/hadits

## 📖 Daftar Koleksi

Data dalam repositori ini mencakup berkas berikut:

- **Abu Dawud** — `abu-dawud.json`
- **Ahmad** — `ahmad.json`
- **Bukhari** — `bukhari.json`
- **Darimi** — `darimi.json`
- **Ibnu Majah** — `ibnu-majah.json`
- **Malik** — `malik.json`
- **Muslim** — `muslim.json`
- **Nasai** — `nasai.json`
- **Tirmidzi** — `tirmidzi.json`
- **Daftar koleksi** — `list.json`

## 🚀 Cara Menggunakan

1. Buka repositori [misntv/hadits](https://github.com/misntv/hadits).
2. Pilih berkas JSON yang dibutuhkan.
3. Unduh berkas atau gunakan URL berkas mentah (*raw*) untuk mengakses data dari aplikasi Anda.
4. Sesuaikan proses pembacaan data dengan struktur JSON pada berkas yang digunakan.

Contoh mengunduh repositori:

```bash
git clone https://github.com/misntv/hadits.git
```

## 💻 Format Data

Data koleksi disimpan dalam format JSON. Struktur dan nama properti dapat berbeda sesuai isi berkas; periksa berkas terkait sebelum mengintegrasikannya ke aplikasi.
